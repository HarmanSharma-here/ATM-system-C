# ATM System in C

A simple console ATM program written in C.

## Features
- PIN login with 3 attempts (card blocks after 3 wrong tries)
- Check balance
- Deposit money
- Withdraw money (with insufficient funds check)
- Change PIN (4 digits only)
- Input validation

## How to run
gcc atm.c -o atm
./atm

## Concepts used
Loops, if-else, variables, scanf/printf
